# RFID-Based Smart Shopping Cart System

## Description
An Arduino-based Smart Shopping Cart System that uses RFID technology to identify products and calculate the total bill automatically. It displays product and billing details on an LCD and uses a buzzer for alerts.

## Features
- RFID-based product identification
- Automatic bill calculation
- LCD display for product and total amount
- Push buttons for navigation and clearing
- Buzzer alerts

## Technologies Used
- Arduino UNO
- Arduino IDE
- C/C++ (Arduino)
- MFRC522 RFID Reader
- 16x2 I2C LCD
- Buzzer and Push Buttons

## Code Files
- `rfid_card_reader.ino`
- `rfid_shopping_cart.ino`

## Applications
- Smart shopping
- Automated billing
- Retail store management
